# Grameen Setu

A farmer-first marketplace concept connecting farmers and buyers through listings, market trends, bidding, messaging, order history, and ratings.

## Frontend preview

This repository includes a static frontend preview published through GitHub Pages. It uses demo data only. The PHP/MySQL backend is not included in this deployment.

## Run locally

Open index.html in a browser, or serve the repo with any static file server.
